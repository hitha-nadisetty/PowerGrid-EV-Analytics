# ⚡ PowerGrid EV Analytics

A comprehensive end-to-end data analytics portfolio project based on EV charging infrastructure data.

## Objectives

This project focuses on analyzing EV charging data to generate business insights, forecast demand, optimize infrastructure, and build machine learning models for real-world decision-making.

## Technologies

- Python
- Pandas
- NumPy
- Scikit-learn
- XGBoost
- Prophet
- Power BI
- GitHub
